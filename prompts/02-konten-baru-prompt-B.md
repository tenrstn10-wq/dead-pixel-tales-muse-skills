# Prompt B: tiap bikin konten baru

Bikin konten baru. Genre acak, durasi minimal 40 detik, ikuti alur di skill dan aturan permanen v2 (shot list dengan minimal 4 framing dan 2 close-up, petunjuk hantu sebelum detik 10, payoff akhir terbaca jelas, mata stickman selalu terlihat, narasi dan POV konsisten, cover tanpa spoiler). Mulai dari langkah 1 (ide).

Opsi (hapus kalau tidak perlu):
- Genre: [horor / twist / komedi gelap / haru-seram]
- Kalau saya bilang "pilih sendiri", pilih ide paling kuat lalu jalan sampai selesai.
